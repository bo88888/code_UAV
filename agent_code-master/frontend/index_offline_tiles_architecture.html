方案 A：PMTiles

推荐用于单机、演示和轻量内网。

一个地图区域对应一个 .pmtiles 文件，不需要单独瓦片服务器。

frontend/tiles/medical_city.pmtiles frontend/vendor/maplibre/ frontend/styles/medical-dark.json

方案 B：MBTiles + TileServer GL

推荐用于多终端和正式部署。

由 Docker 内部瓦片服务统一提供地图样式和矢量瓦片。

tileserver: image: maptiler/tileserver-gl volumes: - ./tiles:/data ports: - "8080:8080"

部署原则

前端库文件本地化，不使用 CDN；瓦片服务和调度 API 均部署在同一内网 Docker 网络。
